# Helpdesk Ticket System

Simple Helpdesk Ticket Management System built using Native PHP, MySQL, HTML, CSS, and JavaScript.

## Features

* View all helpdesk tickets
* Create new ticket
* Edit ticket
* Delete ticket
* Search ticket by subject
* Filter ticket by status
* Automatic ticket status for new tickets
* Automatic created date and time
* Status color indicators
* Ticket pagination
* Total ticket count
* Form validation
* Responsive layout

## Technologies

* PHP Native
* MySQL
* HTML5
* CSS3
* JavaScript
* Apache
* Laragon

## Database Structure

Database name:

`helpdesk_ticket`

Table:

`tickets`

Columns:

* `id` - Auto Increment Primary Key
* `subject` - Ticket subject
* `category` - Hardware, Software, Network, Others
* `description` - Ticket description
* `status` - Open, In Progress, Closed
* `created_at` - Automatically generated date and time

## Installation

### 1. Install Laragon

Install Laragon with PHP, Apache, and MySQL.

### 2. Start Laragon

Open Laragon and click:

`Start All`

Make sure Apache and MySQL are running.

### 3. Copy Project

Copy the project folder into:

`C:\laragon\www`

The final project path should be:

`C:\laragon\www\helpdesk-ticket`

### 4. Create Database

Open HeidiSQL from Laragon.

Create a database named:

`helpdesk_ticket`

### 5. Import SQL

Open the SQL file:

`helpdesk_ticket.sql`

Run the SQL script to create the database and `tickets` table.

### 6. Configure Database Connection

Open:

`config/database.php`

Default Laragon configuration:

* Host: localhost
* Username: root
* Password: empty
* Database: helpdesk_ticket

### 7. Run Application

Open a web browser and access:

`http://localhost/helpdesk-ticket`

## Business Rules

* Subject is required.
* Category is required.
* Description is required.
* New tickets automatically receive `Open` status.
* Ticket ID is generated using MySQL Auto Increment.
* `created_at` is automatically generated by MySQL.
* Users can update ticket status when editing a ticket.
* Users must confirm before deleting a ticket.
